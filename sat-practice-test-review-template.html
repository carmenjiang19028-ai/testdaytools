Math: an inverse-operation error

Original example: Solve 3(x - 2) = 15.

Section / domain / skill
Math / Algebra / Linear equations in one variable
What happened
Missed. I chose x = 3: after getting x - 2 = 5, I subtracted 2 again and moved on without checking.
Correct reasoning
Add 2 to both sides to undo the subtraction: x = 7. Substitute: 3(7 - 2) = 15. With x = 3, the left side is 3, not 15.
Next drill
Solve five linear equations with parentheses. Write which operation you undo at each step, then substitute each result.
Fresh recheck
Tomorrow, solve three unseen equations without notes and check each result by substitution.
Example result and next step
All three checked out, and I could explain each inverse step. Next, include this skill in a mixed algebra set.

Reading and Writing: a correct guess

Original example: The pilot reduced page load times; ___, it did not improve completion rates. Choose the better transition: however or therefore.

Section / domain / skill
Reading and Writing / Expression of Ideas / Transitions
What happened
Guessed correctly. I chose however because it sounded right but could not say why therefore was wrong.
Correct reasoning
The second clause limits the first: the pages loaded faster, but completion rates did not improve. However signals that contrast. Therefore would make the lack of improvement sound like a result of the speedup, a connection the sentence does not establish.
Next drill
On each transition question, identify the relationship before looking at the choices: contrast, result, or addition. Then explain why one tempting option does not fit.
Fresh recheck
Tomorrow, try three unseen transition questions. Count a correct answer as secure only if you can explain the relationship.
Example result and next step
I explained two answers but guessed on the third. Stay with contrast vs. result and say the relationship out loud before choosing.

Find the next official drill

  1. In My Practice, open the Score Details for your completed Bluebook practice test. Under Review, check why your choice failed and why the right one worked.
  2. For a set based on the whole test, choose Get Tailored Practice in My Practice. To practice one skill from your record, use the Student Question Bank and filter by SAT, section, domain, and skill.
  3. Save a few unseen questions for a later check. If the same mistake returns, practice that skill again. If you can explain the reasoning on new questions, try a mixed set under time.

FAQ

How should I record a slow question I got right?

Note the step that took extra time, such as translating the prompt into an equation. Try a few new questions of the same skill untimed first. If the setup is reliable but still slow, compare your timing in a short mixed set.

When should I take another full practice test?

Use a full test to check pacing across both sections. If the same mistake still shows up on fresh questions of one skill, work on that skill before spending another session on a full test.
