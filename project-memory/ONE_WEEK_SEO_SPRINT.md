## Sprint Goal

Compress the first validation cycle from "wait and see" to a 7-day indexing and keyword-discovery sprint.

The realistic target is not guaranteed ranking. The realistic target is:
- Google discovers the site quickly.
- Core URLs are submitted manually.
- Sitemap is submitted.
- Search Console begins showing coverage/indexing state.
- Early impressions or query hints identify which pages to strengthen first.

## Product Principle

Do not create mass-produced thin pages.

Every new page should have at least one practical module:
- Date table.
- Decision table.
- Checklist.
- Timeline.
- Quiz.
- Common mistakes.
- FAQ.
- Official source citations.

The site should feel like a usable test-day tool, not an article directory.

## 7-Day Execution

### Day 1: Technical Indexing Setup

Actions:
- Verify site in Google Search Console with URL prefix.
- Submit sitemap.
- Use URL Inspection to request indexing for Tier 1 URLs.
- Confirm `robots.txt` is live and references sitemap.
- Confirm homepage and sitemap return HTTP 200.

Success signal:
- Search Console accepts the sitemap.
- URL Inspection sees the live page.

### Day 2: Page Depth Push

Actions:
- Publish enhanced homepage.
- Publish deeper AP Score, SAT Dates, Digital SAT, SAT Score, and DMV modules.
- Remove visible ad placeholders until real AdSense is approved.
- Confirm all pages link to related tools.

Success signal:
- Core pages feel complete to a first-time user.
- No page looks like a placeholder.

### Day 3: Long-Tail Page Additions

Actions:
- Add 6 high-intent support pages first.
- Avoid one-template mass generation.
- Each page must have a distinct user problem and module.

Current candidates already added:
- AP score delay/missing score.
- AP credit after scores.
- August 22, 2026 SAT planning.
- Bluebook setup checklist.
- California road signs quiz.
- New York road signs quiz.

Success signal:
- Sitemap includes new pages.
- New pages are reachable from homepage or hub pages.

### Day 4: Manual Submission Round

Actions:
- Submit Tier 2 URLs with URL Inspection.
- Re-submit sitemap if new pages were added.
- Check for indexing errors.

Success signal:
- Google can fetch rendered pages.
- No obvious crawl-blocking issue appears.

### Day 5: First Data Check

Actions:
- Check Search Console Performance and Pages reports.
- Look for impressions, crawled/discovered status, or indexed pages.
- Record any query terms that appear.

Do not panic if clicks are zero.

Success signal:
- Any impression or discovered/indexed state is useful.

### Day 6: Query-Based Refinement

Actions:
- If queries appear, improve matching page titles, intros, FAQs, and internal links.
- If no queries appear, improve internal links and resubmit the top 5 pages.
- Add one small support section to the most promising page.

Success signal:
- Pages become more directly aligned with real query language.

### Day 7: Decision Point

Actions:
- Create a keyword tracker from Search Console data.
- Pick 3 pages to improve next.
- Decide whether to add DMV road-sign pages or AP score support pages first.

Success signal:
- We have a clear next content priority based on data, not guessing.

## Metrics To Watch

Primary:
- Indexed pages.
- Impressions.
- Queries.
- Average position.
- Clicks.

Secondary:
- Page load works on mobile.
- No visible template placeholders.
- No broken internal links.
- No fake contact email.

## Current No-Ad Rule

Do not add real AdSense code yet.

Do not display fake ad boxes.

AdSense comes later, after:
- Search Console shows indexing and some organic activity.
- Pages look complete.
- Real domain/contact email are ready.
- Privacy policy is updated for ads/analytics.

## Expansion Rules

Allowed:
- 6-10 strong long-tail pages.
- Road signs quizzes.
- AP score support pages.
- SAT date/retake pages.

Avoid:
- 50-state DMV expansion before validation.
- Hundreds of near-duplicate AP subject pages.
- AI-generated filler paragraphs.
- Unverified official claims.
- Official logos or copied exam questions.

## Expected Outcome

Best case in one week:
- Several pages indexed.
- First Search Console impressions appear.
- A few long-tail queries show up.

Normal case in one week:
- Sitemap accepted.
- Some pages discovered or crawled.
- Early query data may still be sparse.

Bad case:
- Pages not discovered.
- Fix by improving internal links, resubmitting URLs, and checking technical issues.
