    Name

    Compare last name A–Z, then first name A–Z, then record ID A–Z. Ignore case; do not reverse the displayed fields.

    Alphanumeric compares left-to-right chunks: letters A–Z, then numeric value 0–9. A shorter exact prefix comes first; if numeric values tie, the shorter digit chunk comes first (so A-2 precedes A-02), then record ID A–Z. Dates use ISO YYYY-MM-DD, earliest first, then record ID.
