      Current practice rule

      Name

      Compare last name A–Z, then first name A–Z, then record ID A–Z. Ignore case.

      Alphanumeric

      Compare chunks left to right: text A–Z, numbers by value, and text before numbers when types differ. A shorter exact prefix goes first. For equal numbers, fewer leading zeros goes first (A-2 before A-02). If the entire code ties, compare record IDs A–Z.

      Date

      File the earliest date first using YYYY-MM-DD. If dates match, compare record IDs A–Z.
